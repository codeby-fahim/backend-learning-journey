## 🛠️ How to Run Locally

If you want to run any specific backend project from this repository locally:

1. Clone the repository:
<pre><code>git clone https://github.com/codeby-fahim/backend-learning-journey.git</code></pre>

2. Go to the folder of the specific project:
<pre><code>cd node-basic-server</code></pre>

3. Install the dependencies:
<pre><code>npm install</code></pre>

4. Set up environment variables:
Create a `.env` file in the project root and add your configuration (e.g., `PORT=5000`, `DB_URI=...`).

5. Run the development server:
<pre><code>npm run dev</code></pre>
